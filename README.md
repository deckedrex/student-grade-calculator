# Student Final Grade Calculator

## Project Description

This project is a C++ application that calculates the final grade of a student based on homework results and the exam score.

The program will allow users to enter multiple homework grades and an exam grade. The final result can be calculated using either the **average** or the **median** of the homework results.

The goal of this application is to practice object-oriented programming in C++, including classes, vectors, operator overloading, and file structure management.

## Grade Calculation Formula

The final grade is calculated using the following formula:

Final Grade = 0.4 × Homework Result + 0.6 × Exam Result

Where:

* Homework Result = average or median of homework grades
* Exam Result = exam score entered by the user
